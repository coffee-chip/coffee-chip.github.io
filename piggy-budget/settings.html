    How the buckets work

    Each new day adds 1/30 of the monthly allocation. There is no limit on how much can accumulate over time. Purchases subtract from the balance; you can record a purchase even if it takes the balance below zero. Future daily additions bring it back up.

    Starting funds can be 0, 1, 2, or 3 months of the initial allocation. Changing an allocation affects future daily additions; it does not rewrite earlier spending or additions.

    Developer tools

    Advance the budget date by one day to see each bucket receive one daily addition. This advances all categories and is saved in this browser.
